Example 5.1.1 Using Sigma Notation.

  1. Suppose \(f(x)=3^x\) Write in sigma notation and evaluate the sum of terms \(f(i)=3^i\) for \(i=1,2,3,4,5.\)
    🔗
  2. Write the sum in sigma notation:
    \begin{equation*} 1+\frac{1}{4}+\frac{1}{9}+\frac{1}{16}+\frac{1}{25}. \end{equation*}
    🔗
Solution.
  1. Write
    \begin{align*} \displaystyle{\sum_{i=1}^{5} f(i)=\sum_{i=1}^{5} 3^i}\amp =3+3^2+3^3+3^4+3^5\\ \amp =363. \end{align*}
    🔗
  2. If we write \(1=\dfrac{1}{1}\text{,}\) the denominator of each term is a perfect square. Using sigma notation, this sum can be written as
    \begin{equation*} \displaystyle{ \sum_{i=1}^{5} \frac{1}{i^2}= \sum_{i=1}^{5} g(i)}. \end{equation*}
    where \(g(x)=\dfrac{1}{x^2}\text{.}\)
    🔗
