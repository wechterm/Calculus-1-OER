Example 3.1.11 Finding the Equation of a Tangent Line.

Find the equation of the line tangent to the graph of \(f(x)=1\text{ / }x\) at \(x=2.\)
🔗
Solution.
We can use (3.1.1), but as we have seen, the results are the same if we use (3.1.2).
🔗
\begin{align*} m_{\text{ tan }}\amp=\lim_{x\to 2}\frac{f(x)-f(2)}{x-2}\amp\amp\text{ Apply the definition. }\\ \amp=\lim_{x\to 2}\frac{\frac{1}{x}-\frac{1}{2}}{x-2}\amp\amp\text{ Substitute } f(x)=\frac{1}{x} \text{ and }f(2)=\frac{1}{2}.\\ \amp=\lim_{x\to 2}\frac{\left(\frac{1}{x}-\frac{1}{2}\right)}{\left(x-2\right)}\cdot \frac{2x}{2x}\amp\amp\text{ Multiply numerator and denominator by } 2x \text{ to simplify fractions. }\\ \amp=\lim_{x\to 2}\frac{2-x}{2x(x-2)}\amp\amp\text{ Simplify. }\\ \amp=\lim_{x\to 2}\frac{-1}{2x}\amp\amp\text{ Simplify using } \frac{2-x}{x-2}=-1,\text{ for } x\neq 2.\\ \amp=-\frac{1}{4}\amp\amp\text{ Evaluate the limit. } \end{align*}
We now know that the slope of the tangent line is \(-\frac{1}{4}.\) To find the equation of the tangent line, we also need a point on the line. We know that \(\ds f(2)=\frac{1}{2}.\) Since the tangent line passes through the point \((2,\frac{1}{2})\) we can use the point-slope equation of a line to find the equation of the tangent line. Thus the tangent line has the equation
\begin{equation*} y-\frac{1}{2}=-\frac{1}{4}\left(x-2\right)\text{,} \end{equation*}
or \(\ds y=-\frac{1}{4}x+1.\) The graphs of \(\ds f(x)=\frac{1}{x}\) and \(\ds y=-\frac{1}{4}x+1\) are shown in Figure 3.1.12.
