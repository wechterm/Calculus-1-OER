Example 5.3.19 Finding the Average Value of a Function.

Find the average value of the function \(f(x)=8-2x\) over the interval \([0,4]\) and find \(c\) such that \(f(c)\) equals the average value of the function over \([0,4].\)
🔗
Solution.
The formula states the mean value of \(f(x)\) is given by
🔗
\begin{equation*} \frac{1}{4-0} int_{0}^{4} 8-2x\, dx. \end{equation*}
We can see in Figure 5.3.20 that the function represents a straight line and forms a right triangle bounded by the \(x\)- and \(y\)-axes. The area of the triangle is \(A=\dfrac{1}{2}(\text{base})(\text{height}).\) We have
🔗
\begin{equation*} A=\dfrac{1}{2}(4)(8)=16. \end{equation*}
The average value is found by multiplying the area by \(\dfrac{1}{4-0}.\) Thus, the average value of the function is
🔗
\begin{equation*} \4frac{1}{4}(16)=4. \end{equation*}
Set the average value equal to \(f(c)\) and solve for \(c\text{.}\)
🔗
\begin{align*} 8-2c\amp =\amp 4\\ c\amp =\amp 2 \end{align*}
At \(c=2,f(2)=4.\)
