Item a.

Since \(\ds\lim_{x\to\infty}x^2=\infty\) and \(\ds\lim_{x\to\infty}e^x=\infty\text{,}\) we can use L’Hôpital’s rule to evaluate \(\ds\lim_{x\to\infty}\left[\frac{x^2}{e^x}\right]\text{.}\) We obtain
\begin{equation*} \lim_{x\to\infty}\frac{x^2}{e^x}=\lim_{x\to\infty}\frac{2x}{e^x}\text{.} \end{equation*}
Since \(\ds\lim_{x\to\infty}2x=\infty\) and \(\ds\lim_{x\to\infty}e^x=\infty\text{,}\) we can apply L’Hôpital’s rule again. Since
\begin{equation*} \lim_{x\to\infty}\frac{2x}{e^x}=\lim_{x\to\infty}\frac{2}{e^x}=0\text{,} \end{equation*}
we conclude that
\begin{equation*} \lim_{x\to\infty}\frac{x^2}{e^x}=0\text{.} \end{equation*}
Therefore, \(e^x\) grows more rapidly than \(x^2\) as \(x\to\infty\text{.}\) (See Figure 4.8.22 and Table 4.8.23).
