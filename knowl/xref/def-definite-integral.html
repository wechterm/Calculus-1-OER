Definition 5.2.2.

Let \(f(x)\) be a function defined on an interval \([a,b],\) the definite integral of \(f\) from \(a\) to \(b\) is given by
🔗
\begin{equation*} \displaystyle{\int_{a}^{b} f(x)dx} = \displaystyle{ \lim_{\max \Delta x_i \to 0} }\displaystyle{\sum_{i=1}^n f(x_i^* )\Delta x_i} , \end{equation*}
provided the limit exists. If this limit exists, the function \(f(x)\) is said to be integrable on \([a,b],\) or is an integrable function.
