Example 3.1.18 Finding a Derivative.

For \(f(x)=3x^2-4x+1,\) find \(f'(2)\) by using (3.1.3).
🔗
Solution.
Substitute the given function and value directly into the equation.
🔗
\begin{align*} f'(x)\amp=\lim_{x\to 2}\frac{f(x)-f(2)}{x-2}\amp\amp\text{ Apply the definition. }\\ \amp=\lim_{x\to 2}\frac{(3x^2-4x+1)-5}{x-2}\amp\amp\text{ Substitute } f(x)=3x^2-4x+1 \text{ and } f(2)=5.\\ \amp=\lim_{x\to 2}\frac{(x-2)(3x+2)}{x-2}\amp\amp\text{ Simplify and factor the numerator. }\\ \amp=\lim_{x\to 2}(3x+2)\amp\amp\text{ Cancel the common factor. }\\ \amp=8\amp\amp\text{ Evaluate the limit. } \end{align*}
